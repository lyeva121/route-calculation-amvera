# Расчёт маршрута

Статическое веб-приложение для GitHub Pages.

## Публикация
1. Загрузите все файлы этой папки в корень репозитория (index.html должен быть в корне).
2. Settings → Pages → Source: Deploy from a branch → main → / (root) → Save.
3. Через 1–2 минуты сайт будет доступен по адресу https://<логин>.github.io/<репозиторий>/
